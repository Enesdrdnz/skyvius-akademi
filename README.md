# Skyvius Akademi

Skyvius'un yeni üyeleri için otonom sistemler ve görüntü işleme eğitim platformu.

- `index.html`: platformun tamamı (tek dosya)
- `veri/ornek_ucus_logu.csv`: H-1 kontrol görevinin örnek uçuş logu

Yayın: GitHub'da Settings › Pages › Build and deployment › Deploy from a branch › `main` / `(root)`.
Bu dosyalar `egitim-programi/kaynak/akademi` klasöründeki kaynaklardan `python olustur.py` ile üretilir, elle düzenleme.
